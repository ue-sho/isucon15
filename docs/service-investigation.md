## サービス・主要フロー

ISURealは、通知後に自分の写真を投稿し、友達の写真を閲覧するSNS。写真へコメントと画像リアクション（RealMoji）を送る。Memoriesは自分の過去投稿、認定公開アカウントは一方向フォローを受け付ける。

1. 管理者がリージョン別の投稿期間を開始する。同じリージョンで次の期間が始まると直前の期間は終了する。
2. 対象リージョンの利用者へ通知を作成し、`GET /api/notifications` のSSEで届ける。
3. 利用者が写真を投稿する。時間内の判定は `onTimeDeadline` を使い、日付の `localDate` では判定しない。期限後でも期間終了までは投稿できる。
4. 自分の投稿後に友達フィードを検証・閲覧し、画像・投稿詳細・コメント・RealMoji等を利用する。
5. 友達・フォロー・ブロック・公開範囲による権限、削除、過去履歴・画像の整合性を維持する。

`lateSeconds` は期限から投稿までの経過秒を切り捨て、時間内は0。未知のAPIパスやテーブル名は推測で補わず、コード取得後に追記する。

## サーバー・DB・外部への経路

| サーバー | 固定リージョン | 初期状態の役割（マニュアル） |
|---|---|---|
| asia1 | asia | nginx、Goアプリ |
| europe1 | europe | nginx、Goアプリ |
| america1 | america | nginx、Goアプリ |
| asia2 | asia | 共有PostgreSQL 16 |
| 運営ルーター | 対象外 | 国別転送、遅延・帯域制限。ログイン・変更禁止 |

```text
ブラウザ／ベンチマーカー
  → 運営ルーター（X-Country-Codeで国を選択）
    → asia1 / europe1 / america1 のnginx → アプリ
      → ルーター経由のネットワーク → asia2 のPostgreSQL 16
```

- `JP/KR/CN/AU` → asia1、`GB/DE/FR` → europe1、`US/CA/MX` → america1。ヘッダー省略はJP。
- `X-Country-Code` は対応する大文字の値1つ。不正値・空・小文字・複数値・重複ヘッダーは400。
- クライアントIPの参照元は `X-Client-IP`。ヘッダー省略時はルーターが接続元IPを設定する。
- サーバー間もルーター経由。リージョン間には遅延・帯域制限があり、asia1とasia2は同一リージョン。
- DB接続設定の場所は `/home/isucon/env.sh`。パスワードやファイル全文を記録しない。DB名・ポート・接続プール・テーブル・インデックスはコードと稼働環境を確認して追記する。
- マニュアルには第三者の決済・メール・オブジェクトストレージ等のAPI接続先は明記されていない。**外部APIが存在しないことは未確認**。HTTPクライアント、SDK、画像保存先、アプリ間転送をコード取得後に調べる。
- ポータルはベンチ要求・結果取得・質問の制御経路。アプリの利用者リクエスト処理と区別する。pproteinもチーム側の計測経路で、本番配置は未確認。

リージョン外のDBへの往復回数が負担になり得るのは仮説。まだSQL回数・待ち時間・ベンチを計測していないため、ボトルネックとは断定しない。

## 正しさ・採点の要点

- 書き込み成功後の読み取りにはリージョンをまたいでも結果を反映する。公開範囲・友達・ブロックの変更に5秒の猶予はない。
- 画像URLの署名不正・期限切れ・無効画像は403。投稿削除から5秒後には、期限内の署名URLでも画像を取得できてはいけない。
- 初期ログイン失敗、閲覧権限違反、RealMoji/コメントの権限違反、履歴・画像の不整合、削除画像の残存はFAIL条件。
- リダイレクトは追わない。503は再試行されるが、エラー率・応答時間の判定から除外されない。
- スコアは `Σ(採点件数 × 配点 × リージョン倍率)` の小数切捨て。asia=1、europe/america=1.5。HTTP成功リクエスト数とは一致しない。
- 投稿後の友達フィード検証は通常10点・最後の投稿期間20点、エクスポート20点、RealMoji送信5点、コメント投稿3点、画像取得2点。その他の配点・回数上限は[原文](manual-2026-10-31.md#スコアの計算)を参照する。
- 最終結果は最高点ではなく**最後の負荷走行**。最後がFAILなら最終スコアなし。10:00開始、17:00他チームのリーダーボード更新停止、18:00終了。
